**Especificações do Projeto:**
- **Responsável:** Joe Amado (Concepção, Regras de Negócio, Dev, Banco de Dados, UX/UI, Testes).
- **Stack:** HTML5, Vanilla CSS3 (Alexandria Font), JS ES6+, Supabase (PostgreSQL), MapLibre GL, OpenFreeMap, OSRM API, IndexedDB.
- **Instância Supabase:** `https://ojvxsrvmmkjxfgyczypm.supabase.co`
- **Repositório:** Local (`index.html` SPA monolítica) + Git (`repositoriocpd4-collab/2026Ficai`).
